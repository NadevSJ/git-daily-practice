# git-daily-practice

A daily hands-on repository dedicated to mastering Git and GitHub workflows through consistent, manual practice—writing, testing, and verifying every command from scratch.

- **Started:** 18/11/2026
- **Challenge Duration:** 139 Days (20 Weeks)
- **Repository:** [github.com/NadevSJ/git-daily-practice](https://github.com/NadevSJ/git-daily-practice)

---

## Repository Structure

| Path            | Description                                                                                                             |
| :-------------- | :---------------------------------------------------------------------------------------------------------------------- |
| `projects/`     | Weekly mini-projects built using real-world team workflows (feature branches, pull requests, code reviews, and merges). |
| `notes/`        | Detailed reflections covering what was built, the exact commands used, and improvements for next time.                  |
| `cheatsheet.md` | A growing reference guide of Git and GitHub commands learned throughout the challenge.                                  |
| `log.md`        | A chronological daily log tracking every completed session.                                                             |

## Core Workflow Rules

1. **Manual Execution:** Every file, command, and commit is written and verified manually without automated code generation.
2. **Feature-Branch Discipline:** New features are developed on isolated branches and merged into `main` through reviewed pull requests.
3. **Atomic Commits:** Each commit represents a single logical unit of work following Conventional Commits (`feat`, `docs`, `chore`).
