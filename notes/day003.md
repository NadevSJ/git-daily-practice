2. The noticeable point/points I discovered from today's git & github practices

    Find the answer for - When does Git make a merge commit and when does it fast-forward?

    1. Fast-forward: only the branch I merge in has new commits, so main just moves its label forward. Merge commit: both main and the branch have new commits, so Git makes a new commit with two parents that joins them (or always, with --no-ff).

    2. Fast-forward means main simply moved ahead. A merge commit appears only when both branches have new commits to join.
