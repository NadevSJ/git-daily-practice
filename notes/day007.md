2. The noticeable point/points I discovered from today's git & github practices

   Find the answer for - What do the three marker lines <<<<<<<, ======= and >>>>>>> separate?
   1. The marker <<<<<<< HEAD marks the beginning of the changes on my current active branch (main), ======= acts as the dividing line between the two competing versions, and >>>>>>> lab/day007-conflict marks the end of the incoming changes from the branch I am trying to merge. To resolve it cleanly, I keep the exact line I want, strip out all three marker lines, save the file, and complete the merge with git add and git commit.

   2. A merge conflict is not an error or a broken repository—it is simply Git pausing to ask for human judgment when two branches modify the exact same line differently. Also, viewing git log --oneline --graph -5 afterward clearly visualizes how the branch split off from main and joined back together into a single merge commit.
