2. The noticeable point/points I discovered from today's git & github practices

   Find the answer for - During a merge on main, which branch is --ours and which is --theirs?
   1. When I am on `main` and merge `lab/day008-sides` into it, `--ours` is `main` (the branch I am currently on and merging into), and `--theirs` is `lab/day008-sides` (the incoming branch whose changes I am bringing in).

   2. `git merge --abort` is a clean reset button for a conflicted merge: after I aborted and ran `git status`, the `MERGING` state was gone and the working tree was clean again, and using `git restore --theirs` let me pick the branch's `size = large` version without manually editing conflict markers.
